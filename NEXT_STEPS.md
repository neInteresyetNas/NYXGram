# What needs your Mac / iPhone
1. Install Xcode (version in `versions.json`), run `NYXGram/scripts/nyx-setup.sh` and `nyx-ipa.sh`.
   Expect the first build to take an hour or more and to need fixes. Send the first error you get.
2. Own api_id / api_hash from https://my.telegram.org/apps.
3. Apple ID for Sideloadly (typed into Sideloadly only).
4. Check on a real iPhone: login, messages, Ghost mode, deleted-message history, passcode.
Not done yet (planned, not started): Gifts Studio, NYXGram dashboard, Private Vault, security event log,
message-filter UI, extra chat-organisation features.
